# Pacientes

O módulo de **Pacientes** centraliza todo o histórico cadastral e clínico das pessoas atendidas em sua clínica.

## Como gerenciar pacientes

1. Acesse o menu **Pacientes** na barra de navegação lateral.
2. Utilize os filtros de busca por nome, CPF ou status para encontrar um cadastro existente.
3. Clique sobre o nome do paciente para abrir a ficha completa.

## Cadastrando um novo paciente

1. Clique no botão **Novo Paciente** no canto superior direito.
2. Preencha as informações cadastrais obrigatórias (Nome Completo, Telefone, Data de Nascimento).
3. Preencha informações adicionais, como convênio, endereço e observações.
4. Clique em **Salvar**.

> 💡 **Dica:** Manter o número de WhatsApp preenchido corretamente facilita o envio automático de lembretes de consulta.
